# Video Sniffer for KODI

Video Sniffer 是一个 KODI 视频插件，用来从网页地址中解析可播放的视频流，并在 KODI 中选择清晰度播放。插件内置 `yt-dlp` 作为解析引擎，适合把网页视频地址快速发送到电视或盒子上的 KODI 播放。

## 功能特性

- 手动输入视频网页 URL 并解析可播放流
- 手机浏览器远程输入 URL，发送到 KODI 端解析
- 使用 `yt-dlp` 提取视频信息、缩略图和多清晰度播放地址
- 显示不同格式和分辨率的视频流列表
- 保存最近嗅探记录，默认最多 20 条
- 支持重新嗅探历史记录中的 URL
- 支持从 KODI 中打开原始网页，便于处理登录、人机验证或地区提示
- 支持自定义 User-Agent、忽略 SSL 证书校验和 Cookie 文件

## 适用场景

- 在 KODI 中播放网页视频
- 把手机上复制的视频页面地址发送到电视端播放
- 对同一个视频页面反复尝试不同清晰度或格式
- 对需要 Cookie 或特定 User-Agent 的网页进行解析

## 安装方法

### 方式一：通过 ZIP 安装

1. 打开 KODI。
2. 进入 `插件`。
3. 选择 `从 zip 文件安装`。
4. 选择 `plugin.video.sniffer.zip`。
5. 安装完成后，在视频插件中找到 `Video Sniffer`。

### 方式二：开发目录安装

1. 将整个插件目录复制到 KODI 的 `addons` 目录。
2. 确保目录名和 `addon.xml` 中的插件 id 对应，例如 `plugin.video.sniffer`。
3. 重启 KODI 或刷新插件列表。

## 使用方法

### 手动输入网址

1. 打开 `Video Sniffer`。
2. 选择 `手动输入网址 / Manual Input URL`。
3. 输入视频网页地址。
4. 等待插件解析视频信息。
5. 从列表中选择需要播放的格式或清晰度。

### 手机远程输入

1. 打开 `Video Sniffer`。
2. 选择 `手机远程输入 / Mobile Remote Input`。
3. KODI 会显示一个局域网访问地址，例如 `http://192.168.1.10:8080`。
4. 在手机浏览器中打开该地址。
5. 粘贴视频网页 URL 并发送。
6. KODI 端收到 URL 后自动开始解析。

注意：手机和运行 KODI 的设备需要在同一局域网内。

### 查看历史记录

1. 打开 `最近嗅探记录 / Recent Records`。
2. 选择已解析过的视频记录。
3. 可以直接播放之前保存的流地址，也可以选择重新嗅探。
4. 可通过菜单清除单条记录或清除全部记录。

## 设置说明

插件设置位于 `resources/settings.xml`，当前包含以下选项：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| `User-Agent` | 发送给目标网站的浏览器标识 | Chrome 120 UA |
| `Ignore SSL Verification` | 是否忽略 SSL 证书校验，可用于绕过部分证书错误 | `true` |
| `Cookie File Path` | 可选 Cookie 文件路径，用于解析需要登录状态的网站 | 空 |

Cookie 文件需要使用 `yt-dlp` 支持的 Netscape cookie 格式。

## 工作原理

插件会将用户输入的网页 URL 传给内置的 `yt_dlp.YoutubeDL`，并使用 `extract_info(url, download=False)` 只提取信息而不下载视频。解析完成后，插件从 `formats` 中筛选包含视频编码和播放 URL 的条目，并在 KODI 界面中显示格式、分辨率和说明信息。

当用户选择某个视频流时，KODI 会直接播放该流地址。插件同时会把页面 URL、标题、缩略图和解析出的流列表写入插件数据目录下的 `history.json`，用于后续快速访问。

手机远程输入功能会在 KODI 设备上临时启动一个本地 HTTP 服务，默认端口为 `8080`。手机提交 URL 后，KODI 端读取该 URL 并停止服务。

## 注意事项

- 插件只是解析并播放网页中可获取的视频流，不负责下载视频。
- 支持的网站范围主要取决于内置 `yt-dlp` 版本。
- 某些网站可能需要登录 Cookie、特定 User-Agent、地区网络环境或浏览器验证。
- 手机远程输入服务没有身份认证，只建议在可信任的局域网内使用。
- 如果目标网站的视频流地址有时效性，历史记录中的旧流地址可能会失效，需要重新嗅探。
- 请遵守目标网站服务条款和当地法律法规。

## 常见问题

### 解析不到视频流

可能原因包括目标网站不受当前 `yt-dlp` 版本支持、页面需要登录、页面需要人机验证、视频有地区限制，或目标网站返回了加密/DRM 内容。可以尝试配置 Cookie 文件、修改 User-Agent，或使用 `在浏览器中打开` 先完成验证。

### 播放失败但能解析出清晰度

部分视频流地址有时效性，或者需要特定请求头、Cookie、IP 地址一致性。可以尝试重新嗅探，或在同一网络环境下重新获取 Cookie。

### 手机打不开远程输入页面

确认手机和 KODI 设备在同一局域网内，并检查防火墙是否允许访问 KODI 设备的 `8080` 端口。

### GitHub 推送提示密钥扫描

本项目不应提交真实密钥、账号、Cookie 文件或个人配置。若添加新的解析代码，请避免把密钥、Token 或 Cookie 写入仓库。
